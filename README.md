# Delipat IT — ClickUp Solution Design

## Assignment Two — ClickUp Solution Design

A ClickUp-based billing and work-management solution created for the **Nordvik Consulting** scenario.

**Platform:** ClickUp  
**Client Scenario:** Nordvik Consulting  
**Total People:** 39  
**Project Managers:** 12  
**Delivery Consultants:** 27  
**Evidence Checked:** 20 September 2026

---

## 1. Project Objective

Nordvik Consulting currently manages billing-related work using spreadsheets.

The main goal of this assignment was to check whether **ClickUp can be used to manage billing, WIP, hours variance, reporting, and related workflows**.

The solution was built and tested in a ClickUp workspace using the required Nordvik Consulting data.

The assignment also required identifying which requirements are:

- **NATIVE** — available directly in ClickUp
- **CONFIGURATION** — possible after configuration or using a workaround
- **CUSTOM BUILD** — requires an external integration, custom development, or additional solution
